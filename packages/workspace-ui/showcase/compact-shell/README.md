# Compact Workspace surface Showcase

A complete Hara project for the compact `greenways/hodos-workspace-ui` story.

The Workspace declares Files, Code, and Preview surface identities, selects
Preview, and describes a 1000-pixel responsive breakpoint. The named Gallery
state is `../states/compact.edn`.

Compact surface choice is presentation state. The shell may persist it through
an injected service, while canonical Workspace selection and semantic events
remain application-owned.
