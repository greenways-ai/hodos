# Typed flow Graph Showcase

A complete Hara project for the `greenways/hodos-2d` Graph view.

The `graph` surface contains three typed nodes and two connections. Selection
and node movement are enabled; connection creation, deletion and commands remain
disabled. The named Gallery state is `../states/graph-typed-flow.edn`.

The graph model is declarative data. The Package Gallery cannot execute node
metadata or grant additional graph capabilities.
