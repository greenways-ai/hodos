# @greenways/hodos-viewer-defaults

The first-party Hodos Worlds preset. It composes the neutral browser shell with
the GitHub world source, PlayCanvas renderer, runtime-neutral world model, and
required renderer styles.

Register `hodosViewerDistribution`, grant `network.github` and `world.render`,
then activate `HODOS_DEFAULT_VIEWER_ADDON_ID`. Install the base
`@greenways/hodos-viewer` directly when supplying different adapters.
