# Edit a Hara value

This complete project is the Canvas for the `Editor` package story.

The Showcase selects the Playground `code` surface, which mounts the live Hodos
Editor integration over `src/main.hal`. The named state records the serializable
document, selection, completion and preference model.

Try changing `answer`, selecting a form or evaluating the expression. Source
authority and evaluation remain with the Playground/Hara runtime; the Dev model
describes the state and semantic requests.
