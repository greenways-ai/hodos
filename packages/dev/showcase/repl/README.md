# Use a Hara session

This complete project is the Canvas for the `REPL` package story.

The Showcase opens the live Playground `repl` surface after booting the
`showcase.hodos-dev.repl` namespace. Evaluate `(square 9)` or inspect another
value.

The named state demonstrates the serializable session/transcript model.
Execution, cancellation, history persistence and retained-value services remain
owned by Hara and the host.
