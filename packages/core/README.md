# @greenways/hodos-core

The dependency-free Hodos host contract. It owns add-on discovery, dependency
ordering, capability grants, lifecycle, and typed contribution slots. It does
not import Hara, PlayCanvas, GitHub, OPFS, Hestia, or a browser UI.

The same directory is a Hara source package (`greenways/hodos-core`) containing
the stable `gw.hodos` session, bundle, package, scene, and adaptor primitives.
