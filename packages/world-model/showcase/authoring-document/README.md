# Inspect an authoring transaction

This complete Hara project presents one renderer-neutral Hodos authoring
document. The named EDN state contains entities, collections, an asset, a
prefab, an animation track, a Hara script and editor state.

The selected blocks are translated together by one snapped transaction. The
Showcase stops at the portable value boundary: it does not mount PlayCanvas,
persist a draft, run the script or claim publication authority.
