# @greenways/hodos-runtime-hara

The lazy Hara runtime adapter and compatibility kernel composition. Activating
the add-on verifies that Core, Drafts, Publication, and Authoring contributed
their declared Hara modules before the browser VM is loaded.

Direct runtime imports remain available from `@greenways/hodos-runtime-hara/runtime`
for hosts that do not use the Hodos add-on lifecycle yet.
